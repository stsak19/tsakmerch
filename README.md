# tsakmerch

Σελίδα πώλησης ρούχων σε μορφή 3D κρεμάστρας. Τα ρούχα είναι χωρισμένα ανά είδος: αμάνικα, hoodies, κοντομάνικα.

## Πώς τη βλέπεις

Άνοιξε το `index.html` σε browser. Δεν χρειάζεται build, γιατί η Three.js φορτώνεται από CDN. Για να τη δημοσιεύσεις, ενεργοποίησε το GitHub Pages στο branch `main`.

## Τι κάνει

- Με scroll ή σύρσιμο οι κρεμάστρες γλιστράνε στη μπάρα, ταλαντεύονται και στρίβουν με φυσική κίνηση.
- Με κλικ το ρούχο βγαίνει από την κρεμάστρα. Το σέρνεις για να δεις την πλάτη και διαλέγεις μέγεθος.
- Οι καρτέλες σε πάνε σε κάθε κατηγορία. Δουλεύουν και τα βελάκια, το Enter και το Esc.

Τα ρούχα είναι δοκιμαστικά: τα ζωγραφίζει ο κώδικας και ορίζονται στη λίστα `RAW` μέσα στο `index.html`. Το καλάθι μετράει τα προϊόντα μόνο μέσα στη σελίδα.
